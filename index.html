How it works

📝

Registration

To register for the league, contact the administrator directly — new players are added by an admin, not through self sign-up.

💳

Subscription

Each registered player pays a monthly subscription fee to stay active in the league. Players whose subscription for the current month hasn't been recorded as paid will not appear in the player selectors when recording a match, and can't be added to a match until payment is logged in the Admin tab.

$2 / month
💾

Data backup

The administrator can export a full backup of all players, matches, and payment records as a file, and restore from one, from the Admin tab. Both actions require the PIN.

☁️

Cloud sync

When a Google Sheet is connected, every add, edit, or delete is pushed to it immediately — the screen briefly shows a "Saving…" indicator until it's confirmed, so you always know a change actually made it to the Sheet before moving on. The app also pulls the latest Sheet data automatically every time it's opened or refreshed, so anyone visiting the page always sees current standings.

🔗

Connecting for the first time

The first time an admin PIN is entered on a browser with no Sheet connected yet, the app asks for the Web App URL and secret token before continuing — this can be skipped and set up later from the Admin tab.

🏓

Monthly Session points

Singles: winner earns 5 points, runner-up earns 3 points.
Doubles: each winning player earns 2.5 points, each losing player earns 1 point.

🏆

Tournament points

Tournament matches (singles or doubles) award the winner(s) 1 point and the runner-up(s) 0 points.

⏱️

Match limits

A player may take part in at most 3 Monthly Session matches within any rolling 24-hour period. Tournament matches have no such limit.

🔒

Admin actions

Adding, editing, or removing players and matches, managing subscriptions, and exporting/importing data all require the administrator PIN. Once entered correctly, admin access stays unlocked for 5 minutes before the PIN is required again. Entering the wrong PIN 5 times locks admin access for 30 minutes.

🎁

Store rewards

The more points you accumulate, the bigger your discount on table tennis accessories in the store. Check the Rewards tab for current tiers.
